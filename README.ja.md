# map-view

マーカー付きのインタラクティブな地図を表示するためのWebコンポーネントです。Leafletと国土地理院（GSI）の地図タイルを使用しています。

## デモ

ライブデモはこちら: **https://code4fukui.github.io/map-view/**

## 機能

- Leaflet.jsを使用してインタラクティブな地図を表示します。
- 国土地理院（GSI）の高品質な標準地図タイルを使用します。
- 緯度経度または[Geo3x3](https://github.com/taisukef/Geo3x3/)コードを使用してマーカーを配置できます。
- プリセットカラーまたはカスタムアイコンのURLを使用して、マーカーの外観をカスタマイズできます。
- ポップアップのリンクは、自動的にGoogleマップのルート案内を生成するか、カスタムURLを設定できます。
- グレースケールモードを有効にして、地図をスタイリッシュに表示できます。
- 属性を使用して、地図のサイズと初期ズームレベルを設定できます。
- 属性を変更すると、地図が動的に更新されます。
- ページのスクロール操作を妨げないよう、マウスホイールによるズームはデフォルトで無効になっています。

## 使い方

1. HTMLファイルにモジュールスクリプトをインポートします。
2. `<map-view>`タグを使用し、属性を設定して地図を構成します。

```html
<script type="module" src="https://code4fukui.github.io/map-view/map-view.js"></script>

<!-- 緯度経度と色付きマーカーを使用した基本的な地図 -->
<map-view
  name="Hana道場"
  latlng="35.944571,136.186228"
  zoom="10"
  color="red"
></map-view>

<!-- Geo3x3コードとグレースケールモードを使用した地図 -->
<map-view
  name="Fukui Station"
  geo3x3="E9-3-5-5-5-1"
  zoom="15"
  grayscale="true"
></map-view>
```

## 属性

`<map-view>`要素に以下の属性を設定することで、地図をカスタマイズできます。

| 属性 | 説明 | デフォルト | 例 |
| :--- | :--- | :--- | :--- |
| `name` | マーカーのポップアップに表示されるテキスト。 | - | `"Hana道場"` |
| `latlng` | マーカーの位置を緯度と経度で指定します（`緯度,経度`）。 | - | `"35.944571,136.186228"` |
| `geo3x3` | マーカーの位置をGeo3x3コードで指定します。 | - | `"E9-3-5-5-5-1"` |
| `zoom` | 初期ズームレベルを指定します。 | `13` | `"15"` |
| `color` | マーカーの色を指定します（`red`、`blue`、`green`など）。 | - | `"red"` |
| `icon` | カスタムアイコンのURLを指定します。 | - | `"https://example.com/icon.png"` |
| `grayscale` | グレースケールモードを有効にします（`true`または`false`）。 | `false` | `"true"` |
| `width` | 地図の幅を指定します。 | `"100%"` | `"500px"` |
| `height` | 地図の高さを指定します。 | `"60vh"` | `"300px"` |
